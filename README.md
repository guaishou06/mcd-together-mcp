# 和我一起麦
> 把一个人的点餐，变成两个人的连接。
「和我一起麦」是一套基于麦当劳 MCP 能力构建的双人互动点餐 Skill。
它不只是帮一个人点外卖，而是让异地的两个人进入同一个「互动空间」，共同完成一次点餐。
两个人各自拥有自己的购物车，可以互相查看、添加、删除和修改餐品。一次次购物车的变化，成为双方交流和互动的载体。
最终，两个人分别完成自己的订单，并获得一份属于两个人的「麦麦默契值」。
---
## 项目介绍
传统 AI 点餐更接近：
**Prompt → 推荐餐品 → 下单**
「和我一起麦」希望探索另一种方式：
**Prompt → 互动空间 → 双人互动 → 共同选择 → 真实点餐 → 关系反馈**
项目的核心不是「帮你点餐」，而是把一次点餐变成一次两个人可以共同参与的互动。
### 核心功能
#### 1. 互动点餐
两个人进入同一个互动空间。
双方拥有各自独立的购物车，同时可以看到对方的选择，并进行：
- 添加餐品
- 删除餐品
- 修改购物车
- 互相加餐
- 查看对方当前选择
最终双方分别下单，并配送到各自的地址。
#### 2. 麦麦默契值
完成互动点餐后，系统根据双方购物车中相同商品的重合程度计算「麦麦默契值」。
选择越接近，默契值越高。
一次普通的点餐，因此产生了一个属于两个人的互动结果。

## 目标用户
适合：
- 异地情侣
- 异地朋友
- 同学
- 家人
- 希望与朋友一起吃麦当劳的人
尤其适合两个人虽然不在同一个地方，但希望「一起吃顿饭」的场景。

## 使用方式
### 1. 进入互动空间
两位用户进入同一个「和我一起麦」空间。
### 2. 开始互动
双方浏览麦当劳餐品，并分别操作自己的购物车。
可以给对方加餐，也可以修改自己的选择。
### 3. 完成购物车
双方确认自己的最终餐品。
### 4. 分别下单
双方分别完成订单，并使用各自的配送地址。
### 5. 查看麦麦默契值
系统根据双方购物车的商品重合情况计算本次「麦麦默契值」。

## 技术实现
「和我一起麦」是一个 WorkBuddy Skill，通过 6 个 Python 脚本编排完整流程：

- space.py：互动空间管理（创建/加入/状态机）
- cart.py：双人购物车（增删改查/同步播报/互查互改）
- menu.py：门店上下文与真实菜单导入
- checkout.py：双独立订单编排
- score.py：麦麦默契值计算
- reward.py：默契值 → 专属优惠券

### 关键设计
- 单账号双订单：创建者持有麦当劳主账号，好友凭空间口令加入（无需麦当劳账号），两笔订单独立生成、独立配送。
- 各回各家：每位成员有独立的门店/地址上下文，A 的单送 A、B 的单送 B，菜单按人隔离，绝不串单。
- 默契值公式：双方购物车商品集合的 Jaccard 相似度 × 100，得出 0~100 的「麦麦默契值」。
- 专属优惠券：按默契值档位抽取「和我一起麦」专属优惠券，单笔订单减免 1~2.5 元。

## MCP 集成
本项目基于麦当劳 MCP Server 构建。
MCP 负责提供真实的麦当劳餐品及点餐相关能力，而「和我一起麦」负责将这些能力组织成双人互动体验。
项目实际使用了麦当劳 MCP 的 12 个工具，覆盖门店查询、菜单拉取、价格试算、配送地址、优惠券与下单等环节。

## 项目价值
「和我一起麦」尝试回答一个问题：
> 当 AI 可以越来越轻松地帮我们完成一件事情时，我们是不是也可以让 AI 帮我们创造更多「一起做事情」的机会？
因此，本项目没有把 AI 的目标停留在「替用户完成点餐」，而是希望通过麦当劳 MCP，把真实的餐品和订单能力变成两个人互动的基础设施。
**让 AI 不只是替你完成一件事，而是让两个人一起完成一件事。**&#8203;
